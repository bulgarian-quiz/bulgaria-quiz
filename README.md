# bulgaria-quiz

Опознай България - интерактивен проект свързан с лесно учене на интересни факти за България

**Сайт:** [bulgaria-game.com](https://bulgaria-game.com)

Изходният код на „Опознай България“: история на България от 681 г. до днес, 3D пътуване от Космоса до България, три игри (куиз по 28-те области, подреждане на областите и „Познай мястото“ със снимки), флашкарти, мултиплейър с приятели и AI помощник.

## Технологии

React, TypeScript, Vite, Tailwind CSS, React Three Fiber (3D), Supabase (база данни, вход, realtime и edge функции).

## Пускане локално

```bash
npm install
cp .env.example .env   # попълни с данните на своя Supabase проект
npm run dev
```

Ключовете на проекта не са публикувани тук. Сървърните ключове (например `GEMINI_API_KEY`) се пазят в секретите на Supabase / Lovable Cloud, не във файлове.
